## 7. Nash Bargaining Validation

### Objective

Estimate a bargaining reference price using the buyer's reservation value and the supplier's historical pricing as a prototype supplier reservation-price proxy.

### Calculation

For Supplier C:

- Historical average price = ₹111/unit
- Buyer reservation value per unit = ₹113/unit

Therefore:

**Nash Bargaining Price = (₹111 + ₹113) / 2 = ₹112/unit**

For 10,000 units:

**Nash Total Value = ₹112 × 10,000 = ₹11,20,000**

The result is saved in:

`outputs/nash_bargaining.csv`

### Status

**Validated — calculation is mathematically consistent with the current prototype assumptions.**

### Limitation

Historical average purchase price is being used as a proxy for the supplier's reservation price. It is not the supplier's actual minimum acceptable price and should be calibrated using real negotiation and cost data.
